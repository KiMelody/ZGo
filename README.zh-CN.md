# ZGo

**ZCode — to go.** Flutter 应用(Android / iOS),远程控制桌面端
**ZCode**:原生设备列表、实时任务目录、全原生对话;应用内保留
官方 Web 远程作为兜底。

## 上手

你需要一台运行 ZCode(zcode.z.ai)的桌面设备,在那里生成远程控制
链接;应用内 **添加设备** → 扫码或粘贴 → 点卡片 → 任务列表。

预编译 APK 见 [Releases](https://github.com/KiMelody/ZGo/releases)。

## 源码构建

```bash
flutter pub get
flutter run
flutter build apk --release
```
