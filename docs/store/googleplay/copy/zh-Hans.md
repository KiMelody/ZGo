## 完整说明 Full description(最多 4000)
```
ZLinker 是 ZCode 的移动遥控器——把桌面上的编程智能体装进手机。它直接讲原生协议,因此无需打开网页,就能看到实时状态、真实任务列表和完整的流式对话。

【原生任务列表】
所有设备的任务集中一处:运行状态、最新回复预览、置顶分组。随手停止 / 暂停 / 恢复,点开任务即达对话。

【原生对话体验】
完整的 Conversation V4,用原生控件呈现:流式 Markdown、思考过程、带 diff 的工具调用、文件改动栏、模型 / 模式 / 思考切换、消息队列、附件与历史分页。

【定时自动化】
在手机上创建、编辑、启停服务端定时任务——cron、固定间隔或一次性延迟。即使 App 已关闭,也会在桌面端准时触发。

【闲时任务】
把任务提交到算力空闲时段执行,排队位置实时可见,完成即刻推送。(需 Coding Plan 订阅)

【本地通知】
任务完成 / 失败、闲时结果就绪、自动化触发——直接推送到手机,点通知即可打开对话。这是网页版远程做不到的。

【多设备管理】
扫码、粘贴链接或识别截图即可添加设备。可重命名、置顶、排序,并导出加密备份。每台设备各自维持一条实时连接。

【始终可回退网页】
万一协议变动,任何任务仍可用官方网页版远程打开。原生路径优雅降级,App 照常可用。

【隐私优先】
不收集任何数据。无账号、无我方中转服务器。设备链接只保存在你的手机上。

ZLinker 为独立的社区工具,与 Zhipu AI 无任何关联或背书。请仅用于连接你自己拥有的设备,并遵守 ZCode 的服务条款。
```
