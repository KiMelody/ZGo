## 3. App 功能和目标用户

ZLinker 是 ZCode 桌面端的移动客户端，通过原生协议连接，让开发者在手机上远程查看和管理桌面上的 AI 编程任务：实时任务列表（运行状态、回复预览）、停止/暂停/恢复、完整流式对话（工具 diff、文件改动）、定时自动化、闲时任务队列和推送通知。

目标用户：已经在桌面端使用 ZCode 的开发者，希望在离开电脑时继续监控长时间运行的 Agent 任务。核心价值是把碎片时间（通勤、会议）转化为对 Agent 工作的有效监督。

## 4. 设置和使用说明

无需账号、无需登录、无订阅。App 与用户自己的桌面 ZCode 实例配对：

1. 在桌面端打开 ZCode → 设置 → 远程控制 → 开启。此时会显示二维码和配对链接。
2. 在 ZLinker 中点设备列表的「+」，扫码（或粘贴链接）。设备出现在列表中，带实时连接状态点。
3. 点设备打开任务列表；点任务打开对话。

如审核员没有 ZCode 桌面实例，App 仍会打开并显示空状态（含添加设备指引）；演示视频展示了完整的配对流程。

## 5. 外部服务清单

- **ZCode 桌面实例**（用户自己的机器，WebSocket 直连）— 所有任务/对话数据的来源。
- **Z.ai relay**（`zcode.z.ai`）— 配对二维码通过该 relay 路由，使手机和桌面端跨网络发现彼此。
- **AI 模型**（GLM 系列）— 运行在桌面端 ZCode 实例上，不在 App 内。ZLinker 只负责渲染流式输出。

App 不集成任何支付处理器、分析 SDK、广告 SDK 或第三方数据服务商。
